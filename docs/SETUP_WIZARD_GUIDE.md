## 1. Apa itu Hunter Trades?

**Hunter Trades Journal** adalah aplikasi desktop (jalan di komputer Windows) yang membantu kamu mencatat, menganalisis, dan mempelajari hasil trading-mu.

### 🎯 Dalam Bahasa Sederhana

| Tanpa Hunter Trades | Dengan Hunter Trades |
|---|---|
| Catat trading di Excel manual | Semua catatan otomatis terstruktur |
| Lupa kenapa masuk posisi | Setiap trade punya alasan & strategi |
| Tidak tahu apakah profit atau belum | Statistik win-rate & profit langsung terlihat |
| Strategy bagus hilang begitu saja | Riwayat lengkap bisa dicari & dianalisis |
| Emosi ngacak-ngacak tanpa kontrol | AI assistant bantu evaluasi performa |

### ✨ Fitur Utama

- 📓 **Journal Trading** — Catat semua trade: masuk, keluar, alasan, screenshot
- 📊 **Statistik Otomatis** — Win rate, profit/loss, risk-reward ratio
- 🤖 **AI Assistant** — Tanya apa saja soal trading, dapat jawaban instan
- 🔔 **Daily Briefing** — Ringkasan harian trading-mu
- 💾 **Backup Otomatis** — Data tersimpan aman

## 3. Langkah Install EXE

### 📸 Panduan Visual Step-by-Step

#### Langkah 1: Buka File Installer

📸 *Layar: File `HunterTradesJournal-Setup-v1.x.x.exe` di folder Downloads*

- Buka **File Explorer** (logo folder di taskbar atau tekan `Win + E`)
- Masuk ke folder **Downloads**
- Cari file bernama `HunterTradesJournal-Setup-...exe`
- **Klik dua kali** file tersebut

> ⚠️ **Windows SmartScreen mungkin muncul**  
> Jika muncul pesan *"Windows protected your PC"*, klik **"More info"** lalu **"Run anyway"**. Ini normal karena aplikasi baru belum dikenal Windows.

#### Langkah 2: Konfirmasi User Account Control (UAC)

📸 *Layar: Kotak dialog biru "Do you want to allow this app to make changes?"*

- Klik **"Yes"** untuk memberikan izin install

#### Langkah 3: Pilih Bahasa

📸 *Layar: Jendela Setup Wizard — pilihan bahasa*

- Pilih **"Bahasa Indonesia"** (atau "English" jika lebih nyaman)
- Klik **"Next"** / **"Berikutnya"**

#### Langkah 4: Baca & Terima Lisensi

📸 *Layar: End User License Agreement (EULA)*

- Scroll ke bawah, baca (atau skip — pokoknya harus diterima 😄)
- Centang **"I accept the agreement"**
- Klik **"Next"**

#### Langkah 5: Pilih Folder Install

📸 *Layar: Pilih lokasi install*

| Pilihan | Penjelasan |
|---|---|
| Default `C:\Program Files\HunterTradesJournal` | ✅ **Rekomendasi** — biar default saja |
| Custom folder | Hanya jika kamu sudah paham |

- Klik **"Next"**

#### Langkah 6: Pilih Komponen

📸 *Layar: Pilih komponen yang akan diinstall*

| Komponen | Wajib? | Keterangan |
|---|---|---|
| Hunter Trades Journal (core) | ✅ Wajib | Aplikasi utama |
| Desktop Shortcut | ✅ Ya | Ikon di desktop |
| Start Menu Shortcut | ✅ Ya | Akses dari Start menu |
| MT5 Bridge Connector | ❌ Opsional | Hanya jika pakai MetaTrader 5 |
| Auto-Update Module | ✅ Ya | Update otomatis |

- Klik **"Next"**

#### Langkah 7: Mulai Install

📸 *Layar: Progress bar "Installing..."*

- Tunggu hingga progress bar penuh (± 3–5 menit)
- **Jangan** mematikan komputer atau menutup jendela install

#### Langkah 8: Install Selesai 🎉

📸 *Layar: "Setup was completed successfully"*

- Centang **"Launch Hunter Trades Journal"** jika ingin langsung buka
- Klik **"Finish"**

> 🎊 **Selamat!** Aplikasi Hunter Trades Journal sekarang terinstall di komputermu.

## 5. Verifikasi Service Jalan

Setelah setup selesai, pastikan semua komponen berjalan dengan benar.

### ✅ Checklist Verifikasi

| No | Cara Cek | Hasil yang Benar |
|---|---|---|
| 1 | **Aplikasi terbuka** | Muncul dashboard utama, bukan error |
| 2 | **Login berhasil** | Nama/email muncul di pojok kanan atas |
| 3 | **Koneksi server** | Indikator hijau ✅ di status bar |
| 4 | **AI Assistant** | Coba tanya "Halo, apa kabar?" — harus ada jawaban |

### 🔧 Cara Cek Manual

#### Cek 1: Status Koneksi Server
- Lihat pojok kanan bawah layar
- Hijau ✅ = Terhubung
- Merah ❌ = Terputus → klik untuk reconnect

#### Cek 2: Test AI Assistant
1. Klik ikon **🤖 Chat** di sidebar
2. Ketik: `Apa itu risk-reward ratio?`
3. Tekan Enter
4. Jika ada jawaban, AI berjalan dengan baik ✅

#### Cek 3: Test Database
1. Klik menu **"Journal"** di sidebar
2. Klik **"Trade Baru"**
3. Isi: Symbol `BTCUSD`, Type `Buy`, Lot `0.01`, Entry `65000`
4. Klik **"Simpan"**
5. Trade baru muncul di daftar ✅
6. Hapus lagi jika hanya testing

#### Cek 4: Test Backup
1. Klik menu **"Settings"** → **"Backup"**
2. Klik **"Backup Sekarang"**
3. Tunggu hingga selesai
4. Cek folder backup tujuan — file baru harus muncul ✅

## 6. Troubleshooting Umum

### 🚨 Masalah yang Sering Terjadi

#### 1. ❌ "Cannot connect to server"

| Kemungkinan Penyebab | Solusi |
|---|---|
| Internet putus | Cek Wi-Fi / kabel LAN, coba buka google.com |
| Firewall blokir | Tambahkan exception untuk Hunter Trades di Windows Defender Firewall |
| VPN aktif | Matikan VPN sementara, coba lagi |
| Server maintenance | Cek status di https://status.hunter.trades |

#### 2. ❌ "AI Assistant tidak merespons"

| Kemungkinan Penyebab | Solusi |
|---|---|
| API Key salah/salah provider | Cek Settings → AI → pastikan provider & key benar |
| Kuota AI habis | Cek dashboard provider (OpenAI/Anthropic) |
| Internet tidak stabil | Test dengan buka website lain |
| Model tidak tersedia | Ganti model lain di Settings |

#### 3. ❌ "Aplikasi tidak bisa dibuka / crash"

| Kemungkinan Penyebab | Solusi |
|---|---|
| Install corrupt | Uninstall → download ulang EXE → install ulang |
| Windows tidak compatible | Pastikan Windows 10 64-bit atau lebih baru |
| RAM minimum tidak terpenuhi | Tutup aplikasi lain, pastikan RAM kosong ≥ 2 GB |
| Antivirus blokir | Tambahkan folder aplikasi ke whitelist antivirus |

#### 4. ❌ "Data hilang setelah reinstall"

| Kemungkinan Penyebab | Solusi |
|---|---|
| Backup tidak ada | Cek folder backup di `Settings → Backup` |
| Lokasi database berubah | Cek `C:\Users\[Nama]\Documents\HunterTrades\` |
| Lupa password enkripsi | Sayangnya data tidak bisa dibuka tanpa password |

#### 5. ❌ "MT5 tidak tersambung"

| Kemungkinan Penyebab | Solusi |
|---|---|
| MT5 tidak terinstall | Install MetaTrader 5 dari broker |
| Path MT5 salah | Cek `Settings → MT5 → MT5 Path` |
| MT5 tidak berjalan | Buka MetaTrades 5 dulu, lalu klik "Connect" |
| Akun MT5 salah | Pastikan login & server sesuai broker |

#### 6. ❌ "Windows SmartScreen memblokir install"

**Solusi:**
1. Klik **"More info"** di layar biru SmartScreen
2. Klik **"Run anyway"**
3. Jika tetap tidak bisa, klik kanan file EXE → **Properties** → centang **"Unblock"** → OK

## 8. FAQ

### ❓ Pertanyaan Umum

**T: Apakah Hunter Trades gratis?**  
A: Ada versi free dengan fitur dasar. Versu Pro/ Premium membuka fitur AI penuh, unlimited storage, dan sinkronisasi cloud.

**T: Apakah data saya aman?**  
A: Ya. Data dienkripsi dengan AES-256. Database lokal ada di komputermu. Kamu juga bisa aktifkan enkripsi database.

**T: Bisa pakai di Mac atau Linux?**  
A: Saat ini hanya tersedia untuk Windows (10 & 11). Versi Mac sedang dalam pengembangan.

**T: Apakah perlu internet terus?**  
A: Untuk fitur AI & sinkronisasi cloud, ya. Untuk journal dasar (catat offline), tidak perlu.

**T: Bagaimana cara uninstall?**  
A: Control Panel → Programs → Uninstall a program → pilih "Hunter Trades Journal" → Uninstall. Data tidak terhapus.

**T: Apakah bisa import data dari Excel?**  
A: Ya. Menu **Import** → pilih file Excel/CSV → map kolom → Import.

**T: Bagaimana cara ganti password akun?**  
A: Di website hunter.trades → Settings → Change Password. Password aplikasi ikut berubah.

**T: Apakah MT5 harus selalu berjalan?**  
A: Tidak. MT5 hanya perlu berjalan jika kamu pakai fitur Auto-Sync.

**T: Bagaimana jika lupa Password Enkripsi Database?**  
A: Sayangnya, tidak ada cara memulihkan. Data yang terenkripsi tidak bisa dibuka tanpa password tersebut. Simpan di tempat aman!

**T: Berapa besar storage yang dipakai?**  
A: Rata-rata 1 MB per trade. 1000 trade ≈ 1 GB. Termasuk screenshot bisa lebih besar.

**T: Apakah bisa pakai multi-akun broker?**  
A: Ya. Settings → Brokers → Add Broker. Bisa pakai sekaligus beberapa broker.

**T: Bagaimana cara update aplikasi?**  
A: Jika Auto-Update aktif, aplikasi update otomatis. Atau cek manual: Settings → About → Check for Updates.
