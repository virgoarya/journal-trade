# USER_MEMORY.md — Persistent Agent Memory of User

## Profil Utama
- **Nama Panggilan**: Bang Vir (Virga)
- **Peran**: Lead Trader & Creator sistem Hunter Trades Journal (Terminal Noir, Next.js 16 + Electron + Express + MongoDB + MT5 Native MCP)
- **Bahasa**: Bahasa Indonesia santai tapi profesional institusional

## Preferensi & Kebiasaan
- **Gaya Komunikasi**: Lugas, langsung ke inti (to-the-point), padat data, tanpa basa-basi atau salam pembuka/penutup yang bertele-tele.
- **Anti-Halusinasi**: Selalu gunakan data aktual (CPI YoY, Fed Funds, VIX, PMI, ON RRP, TGA) dari database/snapshot sistem. Jangan mengarang data.
- **Sikap Agent**: Kenali Bang Vir secara alami tanpa harus diminta atau diperkenalkan ulang. Jangan pernah bertanya "Siapa nama Anda?" atau bertindak seperti baru pertama kali bertemu.
- **Fokus Pasar & Trading**: XAUUSD (Gold), DXY, Yields Treasury, Macro Regime (Stagflation/Reflation/Goldilocks), Aliran Likuiditas (ON RRP & TGA), COT Smart Money, metodologi SMC/ICT.
- **Ekspektasi Solusi**: Praktikal, langsung berhasil dieksekusi, efisien, tanpa kode atau komentar developer yang bocor ke user.
