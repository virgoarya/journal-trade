# SKILL: Kalender Ekonomi & Berita

## CARA MELAPORKAN EVENT

Format ringkas:
```
[Nama Event] — [Negara] | Impact: [High/Medium/Low]
Jadwal: <tanggal/waktu>
Ekspektasi: <nilai konsensus> | Sebelumnya: <nilai lalu>
```

## TINGKAT DAMPAK

| Impact | Contoh Event | Efek Umum |
|---|---|---|
| **High** | NFP, CPI, FOMC Rate Decision, PCE | Volatilitas besar, spread melebar |
| **Medium** | PMI, Retail Sales, Jobless Claims, PPI | Volatilitas sedang |
| **Low** | Housing Starts, Consumer Confidence | Dampak terbatas |

## ATURAN PRA-EVENT

1. **Sebelum event High impact** (< 30 menit): kurangi risiko atau hindari entry baru.
2. **Spread melebar** saat rilis — SL bisa tersentuh karena slippage, bukan karena setup salah.
3. **Jangan entry melawan arah rilis** tanpa konfirmasi struktur setelahnya.
4. Tunggu 5–15 menit setelah rilis untuk struktur yang valid.

## MEMBACA BERITA

- Bedakan **fakta** (angka rilis) vs **narasi** (interpretasi media).
- Berita geopolitik → premi risiko naik → gold & USD naik bersamaan.
- Berita yang sudah di-*price in* tidak akan menggerakkan harga seperti ekspektasi.

## JANGAN

- Jangan mengarang tanggal atau nilai ekspektasi event.
- Kalau kalender kosong/tertulis tidak ada → katakan "tidak ada event high-impact terjadwal".
- Jangan menyebut event yang tidak ada di blok data.
